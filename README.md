# Atividade 3 — Livraria Página Viva

Página inicial estática feita com HTML5 e CSS, sem frameworks, bibliotecas, JavaScript ou imagens da internet.


## Requisitos atendidos

- Cabeçalho com nome da livraria como logo e menu de navegação.
- Banner com a chamada “Livros que transformam”.
- Quatro livros em destaque, cada um com capa ilustrativa, título e preço.
- Rodapé com e-mail e localização.
- Estrutura semântica com `header`, `nav`, `main`, `section` e `footer`.
- Mesmo `<div class="menu">` vertical no celular e horizontal no computador, alterado apenas pela media query do CSS.

## Escolhas visuais

A paleta segue o kit de referências: verde-musgo `#4A6B4A` no cabeçalho e rodapé, mostarda `#D4A23A` nos desenhos das capas, off-white `#F5F1E8` no fundo, grafite `#2B2B2B` no texto e branco `#FFFFFF` na seção de produtos. Essas cores dão uma aparência calma, acolhedora e legível.

Os títulos usam Georgia, com serifa para lembrar livros impressos. O texto usa Verdana, sem serifa para facilitar a leitura em telas pequenas. Ambas são fontes disponíveis sem conexão com a internet.

O PDF fornecido não inclui arquivos de capas. Por isso, as quatro imagens são desenhos SVG simples dentro do próprio HTML. Títulos e preços são exemplos para apresentar o layout.
